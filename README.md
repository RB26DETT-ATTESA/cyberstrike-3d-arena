# CyberStrike 3D Arena (Vector Spatial Analyzer)

🎮 **Lightweight 3D Multiplayer Aim Arena for Web Browsers**

A high-performance, single-file 3D multiplayer First-Person Shooter / Aim Training game running entirely in modern web browsers with **zero external image/sound assets**.

Built with:
- **Three.js (r128)**: Ultra-fast 3D vector rendering & spatial physics
- **PeerJS (WebRTC)**: Decentralized serverless P2P multiplayer with authoritative host arbitration & global TURN fallback
- **Web Audio API**: Real-time procedural synthesizer sound effects (gunshots, hits, jumps, jump pads)
- **Gridshot Training**: 5x5 reflex & reaction training mode
- **Dynamic Maps**: Central Fortress, Vertical Maze, Long Range Gallery, and Vertical Apex

## Controls
- **WASD**: Movement
- **Mouse**: Aim & Look (1000Hz gaming mouse smooth accumulator)
- **Left Click**: Shoot (AR / Sniper / DMR)
- **Right Click**: Sniper Scope Zoom & Custom Sensitivity
- **Space / WheelDown**: Jump & Bunny-hopping
- **Shift / C / Ctrl**: Crouch
- **Tab**: Real-time Scoreboard & K/D Ranking
- **1 / 2 / 3**: Weapon Switching
- **Escape**: Lobby / Settings Menu
